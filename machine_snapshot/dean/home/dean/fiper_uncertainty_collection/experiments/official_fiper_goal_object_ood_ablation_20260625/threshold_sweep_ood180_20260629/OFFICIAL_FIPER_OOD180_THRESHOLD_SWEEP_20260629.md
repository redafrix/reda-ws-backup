- No retrain.
- Reuses official FIPER RND checkpoints already trained on in-domain data.
- OOD test set only: 180 episodes = 149 success + 31 failure.
- Scores are official FIPER `tvt_quantile` q=0.95 normalized scores; official deployment point is `any_1`.
- `mass_above_1_M` accumulates `max(0, normalized_score - 1.0)` and alarms when cumulative mass reaches `M`; this is an OOD operating-curve diagnostic, not the unchanged paper deployment rule.
